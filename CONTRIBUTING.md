# Contributing

## Centralized issue tracker

The canonical issue tracker for the entire Clodia project is
[`r-clodia/clodia-platform/issues`](https://github.com/r-clodia/clodia-platform/issues).

Open bugs, feature requests, operational work, and cross-repository tasks there,
regardless of which component contains the affected code. Implementations still
belong in the appropriate component repository; reference the centralized issue
from commits and pull requests.
